# NetLoom

NetLoom — специализированная Windows-система для обнаружения, визуализации, мониторинга и анализа физической L2-топологии сети.

Основной фокус проекта:

- LLDP/CDP;
- FDB/ARP correlation;
- физические связи порт-в-порт;
- RSTP/STP;
- поиск физических колец;
- история изменения топологии;
- ручные неуправляемые элементы;
- русскоязычный интерфейс.

NetLoom не является заменой Zabbix. Zabbix остаётся системой общего мониторинга, а NetLoom специализируется на восстановлении и анализе физической L2-топологии.
