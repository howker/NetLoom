# Sprint 46 — сверка с эталонными макетами ADR-083

Дата: 2026-10-04. Основание: `docs/DECISIONS.md` ADR-083 («Итоговая приёмка — по UI_DESIGN_RULES §10 и эталонным макетам»), `docs/UI_DESIGN_RULES.md` §10 («каждое расхождение — исправлено или явно перенесено в будущий спринт»).

Метод: `Sprint46LiveUiAuditTests` открывает живое окно на копии базы стенда `artifacts/realistic-stand/operator-s46-pass3-visual.db` и сохраняет `artifacts/ui-audit/compare-<раздел>-<тема>.png` — макет 1440×900 слева, текущий экран того же размера справа. Различия, которые объясняются данными стенда (имена устройств, состояние мониторинга «Остановлен» против «выполняется»), расхождениями не считаются.

Статус каждой строки: **открыто** — исправить в Sprint 46; **исправлено** — подтверждено снимком; **перенесено** — с указанием спринта и причины.
