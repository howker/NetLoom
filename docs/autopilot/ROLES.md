# Роли агентов NetLoom

Документ для главной сессии Claude Code. Читается вместе с `CLAUDE.md`; при расхождении в вопросах продукта и правок главнее `CLAUDE.md`.

## Архитектор — главная сессия (Opus)

- Работает по заданию `docs/autopilot/TASK.md`: разбивает пункты на правки и ставит их исполнителю.
- Сам правит только мелочи в одну-две строки; остальное поручает исполнителю с точным заданием: какие файлы, что изменить, по какому правилу, чего не трогать.
- После каждой правки исполнителя:
  1. Просматривает `git diff` и проверяет, что изменено только нужное.
  2. Запускает `powershell -ExecutionPolicy Bypass -File tools\Check-TextEncoding.ps1` и ждёт `EXIT 0`.
  3. Запускает `powershell -ExecutionPolicy Bypass -File tools\Run-UiAudit.ps1`, читает `artifacts\ui-audit-run\run.txt` и `artifacts\ui-audit\findings.txt`.
  4. Для изменений интерфейса сам смотрит `artifacts\ui-audit\compare-*.png` и сверяет с макетами по `docs/UI_DESIGN_RULES.md` §10 и акту сверки.
- Принимает правку или возвращает её с конкретным замечанием. После двух неудачных попыток по одному пункту пункт откладывается с причиной в отчёт, работа идёт дальше.
- Решения принимает по ADR и правилам проекта. Если правила не решают (новое поведение, продуктовый выбор), записывает вопрос владельцу в отчёт и не угадывает.

## Исполнитель правок

- Основной — Codex через плагин: субагент `codex:codex-rescue`. Codex читает `AGENTS.md`.
- Запасной — субагент `editor` (Sonnet), если Codex недоступен или исчерпал лимит.
- Исполнитель не собирает, не тестирует и не коммитит.

## Ветки и коммиты в автономном режиме

- Работа идёт в ветке, указанной в `TASK.md` (вид `sprintNN/тема`), а не в `main`.
- Задание в `TASK.md` — явная просьба владельца коммитить в этой ветке: каждый принятый пункт — отдельный коммит, сообщение на английском, как в истории, перед коммитом `Check-TextEncoding` с `EXIT 0`.
- Ветку задания отправляй на сервер после каждого принятого пункта (`git push -u origin <ветка>`): это резервная копия, подтверждения не нужно.
- Слияние в `main` и отправка `main` — только по команде владельца («мерджим», «отправляй»). Отправка `main` всегда спрашивает подтверждение.
- `reset --hard` и `clean` запрещены.
- Вне автономного режима действует правило `CLAUDE.md`: коммит только по явной просьбе.

## Отчёт

В конце работы — `docs/autopilot/REPORT.md`:

- По каждому пункту: сделан / отложен (почему) / вопрос владельцу; хеш коммита.
- Итог последнего аудита: хвост `run.txt` и число нарушений в `findings.txt`.
- Какие снимки `compare-*.png` владельцу посмотреть в первую очередь.
