# Задание на день

Заполняет владелец утром. Архитектор работает только по этому файлу и по `docs/autopilot/ROLES.md`.

## Ветка

`sprint48/discovery-explain`

## Пункты

1. Итог запуска обнаружения в блоке «Последний запуск» (`BACKLOG.md`, Sprint 48; `docs/sprint46-ui-ux-redesign.md`, раздел Sprint 48, «Итог discovery показывает»).
   - Сейчас в блоке одна строка «Состояние». После завершения или остановки запуска под ней — строки в том же формате «подпись — значение»:
     - «Начат» — время начала, «Длительность» — сколько шёл запуск;
     - «Проверено» — «N из M адресов»;
     - «Найдено» — «K, SNMP ответили: L».
   - Пока запуск идёт, итоговых строк нет; до первого запуска блок остаётся как сейчас («Не запускался»).
   - Данные — только то, что уже есть в WPF: снимок `DiscoveryControlSnapshot` (проверено, всего, найдено) и события найденных кандидатов (`SnmpResponded`); время начала и конца отмечать при смене состояния. Итог живёт до перезапуска приложения: хранение запусков — отдельный пункт «Входящих».
   - Счётчик «ошибок» из плана спринта сюда не входит: ошибки по адресам пока не передаются из Engine — это следующий пункт.
   - Строки — в обоих resx; длительность и числа — по правилам `UI_DESIGN_RULES.md` §3 «Числа»; отступы — токены, как у строки «Состояние».
   - Проверка: тест в `tests/NetLoom.Tests.Unit` на живом окне с подставным `IDiscoveryControl` (как в тестах Sprint 47): запуск → два кандидата, один с SNMP → завершение → строки итога с ожидаемыми значениями; пока запуск идёт, итога нет. Аудит `Run-UiAudit.ps1` без нарушений, снимок раздела «Обнаружение» посмотреть в обеих темах.

## Не трогать

- Схему БД и миграции, если пункт этого прямо не требует.
- Верхнюю строку окна: новые постоянные элементы туда не добавлять.

## Готово, когда

- Все пункты сделаны или отложены с причиной.
- Последний `Run-UiAudit.ps1`: `BUILD_EXIT=0`, `TEST_EXIT=0`, в `findings.txt` нет нарушений.
- Каждый принятый пункт закоммичен и отправлен в ветке задания; `main` не тронут.
- Написан `docs/autopilot/REPORT.md`.

## Команда для запуска

Вставить в окно Code после того, как задание заполнено:

```
/goal Выполнено всё из раздела «Готово, когда» в docs/autopilot/TASK.md; в последнем ответе выведен хвост artifacts\ui-audit-run\run.txt. Или остановись после 40 ходов.
```
