## Решения на подтверждение владельцу

Приняты по правилам проекта (самое узкое толкование), работа не останавливалась; записаны в `BACKLOG.md` (Sprint 48):

1. «Отметить как неуправляемое» — устройство остаётся на карте, SNMP-опрос выключен (как у ручных), устройство подтверждается; категория не меняется. Нужно ли, например, менять категорию на «Неуправляемый коммутатор»?
2. Ошибка адреса при обнаружении показывается, только если адрес ответил по ICMP/TCP или ошибка — не таймаут. Молчащий адрес с таймаутом — «устройства нет».
3. Мониторинг набора, если он уже идёт, перезапускается один раз после запуска обнаружения, добавившего устройства, — чтобы новые устройства опрашивались сразу.
4. У строк «Исключены» нет «Проверить снова» (адрес исключён правилом или игнорирован); для игнорированных — «Отменить игнорирование».
5. Правила исключения профиля теперь применяются (раньше Engine их не получал), но создать правило из интерфейса нельзя — нужен ли редактор правил и в каком спринте?
6. «Неоднозначные» — два случая: адрес принадлежит нескольким устройствам (данные не применяются) и sysName уже есть у устройства на другом адресе (устройство создаётся неподтверждённым).
